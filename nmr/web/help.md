# nmr

Choose **Name**, **Count**, or **Clock**. The page keeps its layout as you change
modes. Long values scroll inside their regions.

## Name

Edit either the true name or description to update the other. In the name editor,
Space accepts the suggested word, Left/Right move through completions, and Up/Down
choose suggestions. Paste a complete name to load it.

## Type

Choose **All types** for full names, or a specific Type for short names and objects
of that type. Changing Type preserves the numeric index. Finite types wrap.

## Count and Clock

Count uses an exact integer and the Increment in Settings. Enable **Automatic**
to play, wait two seconds after completion, and increment. Clock generates its
index from Time or DateTime and decodes it within the selected Type, or globally.
Time only, Display UTC, and Clock interval are in Settings. Description editing
is available only in Name mode.

## Playback

**Play** plays the current name. The Playing area shows its name and notation.
Changing mode or Type lets the current tune finish. Count and Clock remember and
resume Automatic when you return. Keep last played music in Settings controls
whether the last name and score remain visible after playback.

Settings also contains volume, root, position, time signature, and highlight color.
**Copy link** shares the current source, mode, type, index, and increment.
